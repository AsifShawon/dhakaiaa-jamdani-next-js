# Getting Started 

### First Clone the repository in local folder:
```bash
git clone https://github.com/AsifShawon/dhakaiaa-jamdani-next-js.git
```

### Go to `dhakaiaa-jamdani` folder
```bash
cd dhakaiaa-jamdani
```

### Open a Terminal and install the dependencies 
```bash
npm i # npm install
```

### Run the development server:

```bash
npm run dev
# yarn dev
# pnpm dev
# bun dev
```
Now you can access / view the website through [localhost:3000/](localhost:3000/)
